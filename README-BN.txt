1Tap To All — Android Studio project

এই ফোল্ডারটি APK নয়; এটি APK তৈরি করার Android Studio project।

APK তৈরি:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio থেকে এই project folder Open করুন।
3. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
5. APK সাধারণত app/build/outputs/apk/debug/app-debug.apk এ তৈরি হবে।

অ্যাপের বৈশিষ্ট্য:
- ওয়েবসাইটের নাম ও URL যোগ করা
- সাইট সম্পাদনা ও মুছে ফেলা
- অ্যাপের ভিতরে WebView-তে ওয়েবসাইট খোলা
- ওয়েবসাইটের তালিকা ফোনে সংরক্ষণ

নোট:
- ওয়েবসাইট চালাতে ইন্টারনেট প্রয়োজন।
- কিছু ওয়েবসাইট নিরাপত্তা/লগইন নীতির কারণে অ্যাপের ভিতরে না খুলে ব্রাউজারে খুলতে বলতে পারে।
- APK-টি নিজের ফোনে ইনস্টল করার আগে Android নিরাপত্তা সতর্কতা পড়ে নিন।
